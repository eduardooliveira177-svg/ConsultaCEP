# 📍 Consulta de CEP

Projeto desenvolvido para consultar informações de um endereço a partir de um CEP.

O usuário pode informar um CEP e o sistema realiza uma consulta utilizando uma API, retornando informações como rua, bairro, cidade e estado.

## 🚀 Funcionalidades

* Consultar endereço através do CEP
* Exibir rua
* Exibir bairro
* Exibir cidade
* Exibir estado
* Exibir uma mensagem caso o CEP seja inválido
* Abrir a localização do endereço no Google Maps

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* API ViaCEP

## 📂 Estrutura do projeto

```text
consulta-cep/
│
├── index.html
├── resultado.html
├── style.css
├── script.js
└── README.md
```

## 💻 Como utilizar

1. Digite um CEP no campo de consulta.
2. Clique no botão **Consultar Endereço**.
3. O sistema buscará as informações do CEP.
4. Os dados do endereço serão exibidos na página de resultado.

## 🌐 API utilizada

O projeto utiliza a API ViaCEP para realizar a consulta dos endereços.
